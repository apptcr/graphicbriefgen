# Graphic Task System + Google Sheets

ไฟล์ในชุดนี้

| ไฟล์ | ขึ้น GitHub Pages? | หน้าที่ |
|---|---|---|
| `BriefGen.html` | ใช่ | ฟอร์มบรีฟ + พรีวิว + PDF/Excel + ส่งงานเข้าระบบ |
| `Management_Dashboard.html` | ใช่ | Kanban / ตาราง / สำรอง-นำเข้า |
| `cloud.js` | ใช่ (ต้องอยู่โฟลเดอร์เดียวกับ 2 ไฟล์บน) | ตัวเชื่อม Google Sheets + หน้าตั้งค่า |
| `Code.gs` | **ไม่ต้อง** วางใน Apps Script ของ Sheet | backend (ฐานข้อมูล = Google Sheet) |

## ตั้งค่า backend (ทำครั้งเดียว ~5 นาที)

1. สร้าง Google Sheet ใหม่ (ตั้งชื่ออะไรก็ได้)
2. เมนู **Extensions → Apps Script** ลบโค้ดเดิม แล้ววางเนื้อหาจาก `Code.gs`
3. แก้บรรทัด `const TOKEN = '...'` เป็นรหัสผ่านของทีม (อย่างน้อย 8 ตัวอักษร) แล้วกด Save
   (อย่าแก้บรรทัด `DEFAULT_TOKEN`)
4. กด **Deploy → New deployment → ⚙ เลือก Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**  ← ต้องเป็นค่านี้ ไม่งั้นหน้าเว็บเรียกไม่ได้
5. กด Deploy → **Authorize access** → เลือกบัญชี → ถ้าเจอ "Google hasn't verified this app" กด
   *Advanced → Go to (project name) (unsafe)* → Allow (เป็นสคริปต์ของคุณเอง)
6. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
7. ทดสอบ: เปิด URL นั้นในเบราว์เซอร์ ต้องเห็น `{"ok":true,"service":"graphic-tasks",...}`

## เชื่อมหน้าเว็บ

1. อัปโหลด `BriefGen.html`, `Management_Dashboard.html`, `cloud.js` ขึ้น GitHub Pages
2. เปิดหน้าเว็บ → กดป้ายสถานะมุมบนขวา ("โหมดในเครื่อง · เชื่อม Google Sheets")
3. วาง Web app URL + TOKEN → **ทดสอบและบันทึก**
4. ให้คนอื่นในทีม: กด "คัดลอกลิงก์ให้เพื่อนร่วมทีม" ส่งให้ เปิดลิงก์แล้วตั้งค่าให้อัตโนมัติ
   (ลิงก์มีรหัสผ่านอยู่ ส่งเฉพาะคนในทีม — ส่วนหลัง `#` ไม่ถูกส่งไปที่เซิร์ฟเวอร์ GitHub)

ครั้งแรกที่ Dashboard เชื่อมต่อ ถ้ามีงานเก่าในเครื่องที่ยังไม่อยู่ใน Sheets จะมีหน้าต่างถามว่าจะอัปโหลดหรือไม่

## แก้ Code.gs ภายหลัง

หลังแก้โค้ดต้อง **Deploy → Manage deployments → ✏ Edit → Version: New version → Deploy**
(URL เดิมใช้ต่อได้ ถ้ากด New deployment จะได้ URL ใหม่)

## ข้อควรรู้

- **ความปลอดภัย:** ใครมี URL + TOKEN อ่าน/เขียนข้อมูลได้ จึงเหมาะกับทีมภายใน ไม่ใช่ข้อมูลลับระดับสูง
  อย่าเอา TOKEN จริงใส่ในไฟล์บน GitHub และอย่าแชร์ Google Sheet ให้คนนอก
- **ความเร็ว:** Apps Script ตอบช้า ~1–3 วินาที Dashboard ดึงข้อมูลใหม่ทุก 30 วินาที และเมื่อกลับมาที่แท็บ
  (กดปุ่มรูปลูกศรหมุนที่ header เพื่อซิงก์ทันที)
- **เน็ตหลุด:** การแก้ไขถูกเก็บในคิวในเครื่อง แล้วส่งใหม่อัตโนมัติ ป้ายสถานะจะแสดง "รอส่ง N รายการ"
- **แก้ใน Sheet ตรง ๆ ได้:** เพิ่ม/แก้แถวในแท็บ `Tasks` ได้เลย (ห้ามเปลี่ยนหัวคอลัมน์และลำดับคอลัมน์)
  แถวที่เพิ่มเองโดยไม่มี id ระบบจะเติมให้ วันที่กำหนดส่งให้พิมพ์รูปแบบ `2026-06-15T18:00`
- **แก้ชนกัน:** ถ้าสองคนแก้งานเดียวกันพร้อมกัน ฉบับที่ส่งทีหลังจะทับ (last write wins)
- **โควตา:** บัญชี Google ฟรีเรียก Apps Script ได้หลายพันครั้งต่อวัน เพียงพอกับทีมเล็ก
